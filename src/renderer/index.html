Configuración del Análisis

El escaneo básico usa únicamente llamadas masivas y es rápido. Las opciones de análisis profundo inspeccionan cada elemento individualmente y pueden tardar varios minutos y hacer una gran cantidad de llamadas API. Esto último hay que tenerlo en cuenta ya que hay un límite anual. Como ejemplo, para un cliente con 700 Journeys y 200 automatismos puede tardar 10 minutos y hacer 1700 llamadas.

Si ya existe una auditoría guardada para este cliente, se cargará automáticamente al entrar a esta vista.

El script recorre todas las carpetas (para ~6.000 DEs tarda aproximadamente 20 minutos) y te mostrará un popup para copiar el JSON resultante.   1. 
					
    
						
							
							Paso 1: Configurar la Aplicación en Marketing Cloud
						
					
    
					
    
						
    
							
      
								
    • Se deberá crear siempre la app en la BU PADRE y dar permisos a los usuarios. Los permisos se dan en el propio paquete que se ha creado en la pestaña ACCESS
								
      • 
								
    • Si se quiere usar en otras BUs, se debe dar permiso a cada BU y establecer una
									conexción por cada BU.
      • 
								
    • Ve a Setup → Apps → Installed Packages. 
      • 
								
    • Crea un paquete de tipo Web App llamado MC API Helper. 
      • 
								
    • En Redirect URI pon lo siguiente:
									https://127.0.0.1:8443/callback. 
      • 
								
    • Pon los siguientes permisos:
									
        
										
      • Email: Read, Write
        • 
										
      • Automations: Read, Write, Execute
        • 
										
      • Journeys: Read, Write, Activate/Stop/Pause/Resume/Send/Schedule,
											Delete
        • 
										
      • Audiences: Read, Write
        • 
										
      • List and Subscribers: Read, Write
        • 
										
      • Data Extensions: Read, Write
        • 
										
      • Documents and Images: Read
        • 
										
      • Saved Content: Read
        • 
										
      • File Locations: Read
        • 
										
      • Users: Read

    Esta vista está ligada a la de Configuración de Campos y permite establecer la configuración de la Data Extension que se quiere crear.
    
									
    Aquí se debe establecer el Nombre, Descripción (obligatorio) y si es "Sendable". Además, se puede realizar una búsqueda de carpetas para indicar dónde se debe guardar
    
									
    Se puede indicar si es una Data Extension Sendable marcando la casilla correspondiente. Para ello, es necesario haber configurado los campos en Configuración de Campos
									ya que requiere seleccionar uno de ellos para establecer la relación con el suscriptor.

    • Importar un documento con los campos, por ejemplo cuando los copiamos del modelo de datos de Salesforce. Para ello solo se debe pegar el listado de campos e indicar el tipo de separador.
      • 
											
    • Crear/Actualizar Campos, cuando se quieren añadir nuevos campos a una tabla existente o actualizar longitudes en campos
      • 
											
    • Crear campos de ejemplo, para ver cómo se crea un campo de cada tipología
      • 
											
    • Limpiar toda la tabla de campos. Esto siempre mantendrá una fila vacía
      • 
											
    • Añadir filas a la tabla
      • 
											
    • Eliminar filas. Para ello seleccionando una fila, aparecerá una x a la derecha de la fila para poder eliminarla
      • 
											
    • Ordenar filas. Seleccionando una fila y usando las flechas, se puede ordenar la tabla. Esto es interesante sobre todo cuando queremos crear una copia de

Automatismos

					
    
						
  • 
							
    
								Gestión de Automatismos
							
    
							
    
								
    
									
    
										Esta vista muestra todos los automatismos de la instancia en una tabla paginada con los siguientes datos:
										Nombre, Última Ejecución, Próxima Ejecución, Estado y las Notificaciones configuradas para errores y ejecuciones.
									
    
									
    
										Se puede filtrar por nombre (soporta múltiples valores separados por , ; o |) y por estado.
										Las columnas son ordenables haciendo clic en la cabecera.
									
    
									
    Botones disponibles:
    
									
      
										
    • Refrescar — Recarga los datos desde la API.
      • 
										
    • Analizar (requiere selección de 1) — Abre la vista de análisis detallado del automatismo seleccionado.
      • 
										
    • Cargar Notificaciones — Obtiene los emails de alerta configurados en cada automatismo y los muestra en la tabla.
      • 
										
    • Exportar — Descarga un CSV con los datos visibles (respetando los filtros activos).
      • 
										
    • Activar (requiere selección) — Activa automatismos que están parados o pausados.
      • 
										
    • Ejecutar (requiere selección) — Lanza una ejecución manual inmediata.
      • 
										
    • Parar (requiere selección) — Detiene automatismos en ejecución o programados.
      • 
										
    • Clonar (requiere selección de 1) — Navega al clonador selectivo de ese automatismo.
      • 
									
    
									
    
										Los botones de acción (Activar, Ejecutar, Parar) solo se habilitan cuando los automatismos seleccionados tienen un estado compatible con la acción.
										Si se seleccionan varios con estados distintos, los botones quedan deshabilitados.

										Accesible desde la vista de Automatismos seleccionando uno y pulsando Clonar.

										Configuración disponible:
									
    
									
      
										
    • Nombre Destino — Nombre del nuevo automatismo (editable).
      •

      • 
										
    • Por cada actividad del automatismo se puede indicar si clonarla o reutilizar la original, y se puede cambiar el nombre y la Data Extension de destino.
      • 
										
    • Se puede establecer una carpeta de DEs por defecto para que todas las DEs clonadas se guarden ahí sin tener que configurarlas una a una.
      •

								Generador de Diagramas Entidad-Relación (ERD)
							
    
							
    
								
    
									
    
										Esta funcionalidad genera un diagrama visual de las relaciones entre Data Extensions de un Attribute Group de Contact Builder.
										Es útil para entender el modelo de datos del cliente de un vistazo.
									
    
									
    
										El proceso tiene dos pasos (pestañas):
									
    
									
      
										
    • 
											1. Extraer JSON — Hay que abrir el enlace que proporciona la app (apunta a la API interna de Attribute Groups de MC) y ejecutar el script en la consola del navegador.
											El script muestra un popup donde seleccionar qué Attribute Group analizar y genera el JSON de las relaciones.
										
      • 
										
    • 
											2. Generar Diagrama — Se pega el JSON extraído en el cuadro de texto y se pulsa Generar Diagrama.
											Opcionalmente se puede marcar Ocultar tabla Contacts para simplificar el diagrama (la tabla Contacts se marca con 🔑 en los campos que la referencian).
										
      • 
									
    
									
    
										El diagrama resultante es interactivo:
									
    
									
      
										
    • Las tablas son arrastrables para reorganizar el layout.
      • 
										
    • Al hacer clic en un campo se resalta la relación correspondiente (líneas de FK/REF).
      • 
										
    • Los campos se colorean según su tipo: 🟠 PK, 🟢 FK, 🟣 REF.
      • 
										
    • Al pasar el ratón sobre un campo se muestra un tooltip con el tipo de dato y la relación.
      • 
										
    • Se puede descargar el diagrama como imagen (Descargar Imagen) o exportar las relaciones como CSV (Descargar CSV).
      • 
										
    • El botón Nuevo Diagrama limpia el lienzo para empezar con otro Attribute Group.

Auditoría

					
    
						
  • 
							
    
								Auditoría de Instancia
							
    
							
    
								
    
									
    
										Esta vista realiza un análisis completo del estado de la instancia de Marketing Cloud y genera un dashboard con KPIs y gráficos para cada área.
										Si ya existe una auditoría guardada para el cliente activo, se carga automáticamente al entrar a la vista.
									
    
									
    
										El análisis se organiza en seis pestañas de resultados: Usuarios, Automatismos, Journeys, Cloud Pages, Send Management y Data Extensions.
									
    
									
    
										Antes de lanzar el escaneo se pueden activar opciones de análisis profundo:
									
    
									
      
										
    • 
											Automatismos — Análisis Profundo (lento: 2 llamadas por automatismo + 1 por SQL/SSJS) — Detecta email de alerta por error, extrae dominios de aviso, detecta descripciones en SQL/SSJS y genera un mapa de actividades compartidas entre automatismos.
										
      • 
										
    • 
											Journeys — Análisis Profundo (rápido si la API devuelve actividades en la llamada de lista) — Detecta nodos Salesforce activos, calcula el mix multicanal real (Email, SMS, Push/In-App, WhatsApp) e identifica journeys con solo lógica (sin envíos).
										
      • 
										
    • 
											Data Extensions — Análisis desde JSON — Para auditar las DEs hay que ejecutar un script en la consola del navegador estando en Contact Builder. El script recorre todas las carpetas (puede tardar ~20 min para ~6.000 DEs) y genera un JSON que se pega en la vista. Las DEs de la carpeta Shared se excluyen automáticamente.
											Atención: Cada escaneo sobreescribe la caché anterior.
										
      • 
									
    
									
    
										Métricas disponibles por área:
									
    
									
      
										
    • Usuarios: total, activos, inactivos, API users, último login, roles más frecuentes.
      • 
										
    • Automatismos: total, activos/programados, sin historial de ejecución, que lanzan Journeys, actividades de import/export, nombres de prueba.
      • 
										
    • Journeys: total, publicados, por tipo/subtipo/estado, integración con Salesforce, mix de canales, con/sin Goals, con/sin criterios de salida, inactividad.
      • 
										
    • Cloud Pages: total, por tipo, publicadas vs no publicadas.
      • 
										
    • Send Management: Send Classifications, Sender Profiles, perfiles en uso vs huérfanos, remitentes dinámicos, AutoReply y Forward.
      • 
										
    • Data Extensions: total, sin descripción (por propietario), sendable/testable, con retención, vacías, con nombre de prueba, carpetas con más de 15 DEs.
      • 
									
    
									
    
										Haciendo clic en cualquier barra de los gráficos se abre un modal de detalle con la lista de elementos que componen esa métrica, exportable en CSV.
									
    
									
    
										Una vez completada la auditoría están disponibles dos botones:
									
    
									
      
										
    • Descargar PDF — Genera un informe PDF con todos los gráficos y KPIs.
      • 
										
    • Exportar Detalles — Descarga un ZIP con un CSV por cada categoría auditada.
      • 
									
    
									
    
										Los resultados se guardan automáticamente en disco para el cliente activo y se cargan la próxima vez que se acceda a la vista.
										El botón Volver a Opciones permite relanzar el escaneo con diferentes opciones (sobreescribiendo la caché anterior).
